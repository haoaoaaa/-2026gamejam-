5.对话--玩家与B进行海龟汤，可以向B提问给出问题中的一个，B会回答是或不是（海龟汤具体问答流程
汤面：我在寝室里是一个爱笑的人。自从来到这里，我不再笑了。当我离开这里，我又能笑了。
问题：
“这里”是寝室里吗 是
“这里”是寝室的某个位置吗 是
“这里”是床上吗 不是
“这里”是衣柜里吗 是
“这里”是卫生间吗 不是
“这里”是书桌吗 不是
“我”是因为什么原因必须不笑吗 是
“我”被霸凌了吗 不是
“我”不笑与室友有关吗 是
“我”在憋笑吗 是
“我”在和室友玩游戏吗 是
“我”在和室友玩憋笑挑战吗 不是
“我”在和室友捉迷藏吗 是
“我”最后离开“这里”了吗 是
“我”离开后的笑是因为开心吗 是
问题乱序出现，形式类似归寂问答（没看懂的话问我哦）
谜底线索词：寝室 床 衣柜 卫生间 坑 书桌 憋笑 难过 开心 不想笑 霸凌 室友 游戏 捉迷藏 赢 输（提示：选择你认为与汤底相关的六个词吧）
玩家只能选择其中六个
正确线索词为：衣柜 憋笑 室友 捉迷藏 赢 开心
玩家正确选择所有词后，出现完整汤底：
我在和室友玩捉迷藏。为了赢得这场游戏，我藏进了衣柜，努力憋笑。当我出了衣柜，赢得了这场游戏，我很开心，所以笑了。
出现完整汤底后，衣柜一词标红
